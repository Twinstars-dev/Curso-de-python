
# 🤖 Automate the Boring Stuff with Python

## About this Repository

This repository contains my personal solutions, notes, and practice projects while studying **Automate the Boring Stuff with Python** by **Al Sweigart**.

I'm using this repository to reinforce my Python fundamentals by solving every exercise and building practical automation scripts. Instead of simply copying the examples from the book, I also try to improve, refactor, and experiment with different solutions whenever possible.

The main objective is to develop strong programming habits and gradually build a portfolio of Python projects.

---

## Objectives

- Learn Python through hands-on practice.
- Understand automation techniques for everyday tasks.
- Improve problem-solving and logical thinking.
- Practice writing clean, readable, and organized code.
- Build a public record of my learning progress.

## Learning Approach

While studying each chapter, I usually follow this workflow:

1. Read the chapter carefully.
2. Complete every exercise.
3. Solve the practice projects.
4. Add comments to better understand the code.
5. Refactor the solutions whenever I find a better approach.
6. Commit the progress to GitHub.

This helps me track my improvement over time and makes it easier to revisit previous concepts.
